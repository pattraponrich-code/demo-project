# Log - 2026-08-02

## สร้างเอกสาร requirement: ระบบสั่งกาแฟที่โต๊ะผ่าน QR Code

- **ไฟล์:** [[../01-requirements/01-spec/20260802-001-table-ordering-qr|20260802-001-table-ordering-qr]]
- **การตัดสินใจ:** สร้างเอกสารใหม่ (เป็นเอกสาร requirement ฉบับแรกของโปรเจกต์ ยังไม่มีเอกสารเดิมที่เกี่ยวข้อง)
- **สรุป:** ระบบให้ลูกค้าสแกน QR Code ที่โต๊ะเพื่อสั่งกาแฟผ่านหน้าเว็บ เลือกจ่ายทันทีหรือจ่ายทีหลังที่เคาน์เตอร์ได้ และแจ้งเตือนออเดอร์ไปยังบาร์/ครัวแบบเรียลไทม์ ใช้กับร้านสาขาเดียว
