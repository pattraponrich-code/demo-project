# Log - 2026-08-02

## สร้างเอกสาร requirement: ระบบสั่งกาแฟที่โต๊ะผ่าน QR Code

- **ไฟล์:** [[../01-requirements/01-spec/20260802-001-table-ordering-qr|20260802-001-table-ordering-qr]]
- **การตัดสินใจ:** สร้างเอกสารใหม่ (เป็นเอกสาร requirement ฉบับแรกของโปรเจกต์ ยังไม่มีเอกสารเดิมที่เกี่ยวข้อง)
- **สรุป:** ระบบให้ลูกค้าสแกน QR Code ที่โต๊ะเพื่อสั่งกาแฟผ่านหน้าเว็บ เลือกจ่ายทันทีหรือจ่ายทีหลังที่เคาน์เตอร์ได้ และแจ้งเตือนออเดอร์ไปยังบาร์/ครัวแบบเรียลไทม์ ใช้กับร้านสาขาเดียว

## สร้างเอกสาร requirement: การเก็บ Log ของระบบ และการปฏิบัติตาม PDPA เบื้องต้น

- **ไฟล์:** [[../01-requirements/01-spec/20260802-002-system-log-pdpa|20260802-002-system-log-pdpa]]
- **การตัดสินใจ:** สร้างเอกสารใหม่ (เป็นหัวข้อ/ฟีเจอร์คนละเรื่องจาก 001 แม้จะต่อยอดกัน จึงแยกเอกสารและใส่ wikilink อ้างอิงไป-มาระหว่างสองเอกสาร)
- **สรุป:** กำหนดให้ระบบบันทึก audit log และ transaction log ของการทำงานพนักงาน/ธุรกรรม โดยจำกัดสิทธิ์เข้าถึงเฉพาะเจ้าของร้าน/แอดมิน เก็บไว้ 90 วันแล้วลบอัตโนมัติ พร้อมมาตรการ PDPA แบบง่าย (ขอข้อมูลลูกค้าเฉพาะกรณีออกใบเสร็จ/ใบกำกับภาษี พร้อม consent และ privacy notice แบบสั้น) เหมาะกับร้านกาแฟสาขาเดียว
