# 001 - ระบบสั่งกาแฟที่โต๊ะผ่าน QR Code

**วันที่สร้าง:** 2026-08-02
**สถานะ:** Draft
**อ้างอิงจาก:** ไม่มี

## ที่มา / บริบท

เจ้าของร้านกาแฟต้องการให้ลูกค้าที่มานั่งในร้านสามารถสั่งกาแฟได้จากโต๊ะของตัวเองโดยตรง โดยไม่ต้องเดินไปต่อคิวสั่งที่เคาน์เตอร์ เพื่อลดความแออัดหน้าเคาน์เตอร์และเพิ่มความสะดวกให้ลูกค้า

## ข้อกำหนด (Requirements)

- ลูกค้าสแกน QR Code ที่ติดอยู่บนโต๊ะ เพื่อเปิดหน้าเว็บสั่งเครื่องดื่ม (ไม่ต้องติดตั้งแอพ)
- ลูกค้าสามารถเลือกเมนู เพิ่มลงตะกร้า และยืนยันคำสั่งซื้อได้จากหน้าเว็บ
- ระบบต้องรองรับการชำระเงิน 2 รูปแบบ โดยให้ลูกค้าเลือกได้เองตอนสั่ง:
  1. จ่ายทันทีผ่านระบบออนไลน์ (พร้อมเพย์ / บัตร / e-wallet) ก่อนออเดอร์เข้าครัว
  2. สั่งก่อน แล้วไปชำระเงินที่เคาน์เตอร์ภายหลัง
- เมื่อลูกค้ายืนยันคำสั่งซื้อ (และชำระเงินสำเร็จ ในกรณีจ่ายทันที) ออเดอร์ต้องถูกส่งไปแจ้งเตือนที่บาร์/ครัวแบบเรียลไทม์ ผ่านจอ/หน้าจอแสดงรายการออเดอร์ใหม่ ให้บาริสต้าเห็นและรับออเดอร์ไปทำ
- ระบบต้องระบุหมายเลข/ตำแหน่งโต๊ะกำกับไว้ในแต่ละออเดอร์ เพื่อให้พนักงานเสิร์ฟถูกโต๊ะ

## User Story / Use Case

- ในฐานะลูกค้าที่นั่งอยู่ที่โต๊ะ ฉันต้องการสแกน QR Code แล้วสั่งกาแฟได้เลย โดยไม่ต้องลุกไปต่อคิว
- ในฐานะลูกค้า ฉันต้องการเลือกได้ว่าจะจ่ายเงินตอนสั่งเลย หรือไปจ่ายที่เคาน์เตอร์ทีหลัง
- ในฐานะบาริสต้า ฉันต้องการเห็นออเดอร์ใหม่ที่เข้ามาแบบเรียลไทม์ พร้อมหมายเลขโต๊ะ เพื่อจะได้ทำเครื่องดื่มและเสิร์ฟถูกที่

## กฎทางธุรกิจ (Business Rules)

- ออเดอร์ที่เลือก "จ่ายทันที" จะถูกส่งเข้าคิวของบาร์ก็ต่อเมื่อชำระเงินสำเร็จแล้วเท่านั้น
- ออเดอร์ที่เลือก "จ่ายทีหลัง" จะถูกส่งเข้าคิวของบาร์ทันทีที่ลูกค้ายืนยันคำสั่งซื้อ โดยไม่ต้องรอการชำระเงิน
- แต่ละ QR Code ผูกกับหมายเลขโต๊ะที่แน่นอนหนึ่งโต๊ะ

## ขอบเขต (Scope)

### อยู่ในขอบเขต (In scope)
- หน้าเว็บสั่งอาหาร/เครื่องดื่มสำหรับลูกค้า (เข้าผ่าน QR Code ที่โต๊ะ)
- การชำระเงินออนไลน์ (จ่ายทันที) และการสั่งแบบจ่ายทีหลังที่เคาน์เตอร์
- จอ/หน้าจอแจ้งเตือนออเดอร์ใหม่สำหรับบาร์/ครัวแบบเรียลไทม์
- รองรับการใช้งานในร้านกาแฟสาขาเดียว

### ไม่อยู่ในขอบเขต (Out of scope)
- ระบบจัดการเมนู/สต๊อกวัตถุดิบแบบเต็มรูปแบบ
- ระบบบัญชี/รายงานยอดขายเชิงลึก
- การรองรับหลายสาขา (multi-branch)
- แอพมือถือเฉพาะของร้าน (ใช้หน้าเว็บผ่านเบราว์เซอร์แทน)
